3. Utilizando tabelas verdade, verifique as seguintes relações de equivalência:
a) ~(p → q) ≡ p ∧ ~q
b) (p ∨ q) ∧ ( p ∧ q ) ≡ (p ∧ q)
c) p → ~q ≡ ~(p ∧ q)

6. Demonstre as relações abaixo utilizando as equivalências notáveis:
a) p → q ∧ r ⇔ ( p → q ) ∧ ( p → r )

b) p → q ∨ r ⇔ ( p → q ) ∨ ( p → r )

c) p ∧ q → r ⇔ p → ( q → r )

d) ~( ~p → ~q ) ⇔ ~p ∧ q

e) ~~(p v q) ^ ~(r → ~p) ⇔ p ^(p v q) ^ r
